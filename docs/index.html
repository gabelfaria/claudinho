Pronto em um minuto

Ready in a minute

O instalador faz tudo e não pede administrador.

The installer does it all, no admin rights needed.

  1. Cole o comando no PowerShell.Paste the command into PowerShell. Se faltar o Claude Code, ele instala pelo instalador oficial e abre o login. If Claude Code is missing, it installs it with the official installer and opens the login.
  2. Diga como quer ser chamado.Tell it your name. Ele entra no menu Iniciar e passa a abrir com o Windows. It joins the Start menu and starts with Windows.
  3. Clique na bolhinha.Click the bubble. Pronto. Para deixar com a sua cara, edite o prompt.md em %APPDATA%\Claudinho. Done. To make it yours, edit prompt.md in %APPDATA%\Claudinho.

Perguntas frequentes

FAQ

Preciso pagar alguma coisa?Do I need to pay for anything?

O Claudinho é grátis. Ele usa o Claude Code com a sua assinatura do Claude (Pro ou Max), sem chave de API.

Claudinho is free. It uses Claude Code with your own Claude plan (Pro or Max), no API key.

Meus dados vão para algum lugar?Where does my data go?

Conversa, memória e configurações ficam em arquivos no seu PC. As mensagens só vão para a Anthropic, pela sua conta do Claude Code. Não há servidor nem telemetria.

Chat, memory and settings stay in files on your PC. Messages only go to Anthropic through your own Claude Code account. No server, no telemetry.

Ele pode fazer coisas perigosas no meu PC?Can it do risky things on my PC?

Ele roda no modo de permissão automático do Claude Code: o que é seguro roda direto, e o que precisa de aprovação aparece como Permitir/Negar no chat. As verificações automáticas são só leitura.

It runs in Claude Code's auto permission mode: safe actions run, anything that needs approval shows up as Allow/Deny in the chat. Automatic check-ins are read-only.

Funciona no Mac ou no Linux?Does it work on Mac or Linux?

Por enquanto só no Windows 10/11. A bolha e a bandeja usam Win32 direto para ficar leve.

Windows 10/11 only for now. The bubble and tray use Win32 directly to stay lightweight.

A interface tem inglês?Is the interface in English?

Os botões estão em português por enquanto; o Claudinho responde no seu idioma. Inglês está nos planos, e contribuições são bem-vindas.

Buttons are in Portuguese for now; Claudinho replies in your language. An English UI is on the roadmap, and contributions are welcome.
